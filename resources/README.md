Resources
=========

This directory currently serves more than one purpose.

Contents
--------

- committed assets used by the app, including overlay backgrounds and deck imagery
- committed assets used for training or experimentation
- local generated material such as masks, extracted frames, and training datasets

Current State
-------------

The directory is not yet normalized into separate app-assets and generated-data areas.

Much of the generated or machine-local content under `resources/` is intentionally kept out of version control by the current ignore rules. Tracked files in this directory remain part of the repo, but new generated content is generally expected to stay local.
